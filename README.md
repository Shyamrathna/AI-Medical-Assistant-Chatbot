# 🩺 AI Medical Assistant Chatbot

An **AI-powered Medical Assistant Chatbot** developed using **Python, Streamlit, and Large Language Models (LLMs)** to provide disease-related information, symptom-based guidance, and healthcare assistance through an interactive chatbot interface.

This project aims to improve accessibility to basic medical knowledge by helping users understand symptoms, medical conditions, and general healthcare-related queries in a user-friendly manner.

## 🚀 Features

* 💬 Interactive AI medical chatbot
* 🩺 Disease-related information and guidance
* 🤒 Symptom-based assistance
* 📚 General healthcare question answering
* 🧠 AI-powered response generation using LLMs
* 🎨 User-friendly Streamlit interface

## 🛠️ Technologies Used

* **Python**
* **Streamlit**
* **Natural Language Processing (NLP)**
* **Groq API / OpenAI API**
* **Machine Learning Concepts**

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Shyamrathna/AI-Medical-Assistant-Chatbot.git
```

### 2. Navigate to the Project Folder

```bash
cd AI-Medical-Assistant-Chatbot
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Set API Key

Create a `.env` file and add your API key:

```env
GROQ_API_KEY=your_api_key_here
```

or

```env
OPENAI_API_KEY=your_api_key_here
```

### 5. Run the Application

```bash
streamlit run app.py
```
